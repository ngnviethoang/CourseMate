# 📚 CourseMate

## 🚀 Key Features

### 👤 Authentication & Authorization
- User registration & login (JWT, Google Sign-In)
- Role-based access control (Admin, User)
- Refresh token support

---

### 📖 Course Management
- Create, update, delete courses (Admin)
- Course listing with pagination & search
- Course details view

---

### 🗂️ Category Management
- Hierarchical categories (multi-level)
- Filter courses by category

---

### 🛒 Shopping & Orders
- Add/remove courses to cart
- Checkout process
- Order management

---

### 💳 Payment Integration
- VNPAY payment gateway integration
- Handle transaction response codes
- Payment status tracking

---

### ⭐ Reviews & Ratings
- Users can review and rate courses
- Display average rating

---

### 🔍 Search & Filtering
- Search courses by name/keyword
- Filter by category, price, rating

---

### ⚡ Real-time Features
- Real-time updates using SignalR (chat / notifications)

---

### 📦 Course Availability
- Manage course availability
- Track enrollment limits (if applicable)
